# Kamasoutra's Homebrew tap

```sh
brew install --cask kamasoutra/tap/encore
```

| Cask | App |
| --- | --- |
| `encore` | [Encore](https://github.com/Kamasoutra/encore), a native clipboard manager for macOS |

Casks are updated automatically when a new version is released. Encore updates itself, so `brew upgrade` is only needed if you turned automatic updates off.
